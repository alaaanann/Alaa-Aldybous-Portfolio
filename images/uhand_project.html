'Uhand': Bionic Hand Control System Integration

Spring 2024 Arduino / STM32 Systems Integration Wireless Control Robotics
Download Full Report (PDF)

The Challenge

Bionic hands are rapidly evolving from utilitarian tools to complex bioengineering systems that restore natural movement and dexterity. Building and programming a multi-degree-of-freedom (DOF) robotic palm requires a highly flexible control system. The objective of this project was to successfully assemble the hardware and engineer the software algorithms required to translate human input commands—via remote controllers and mobile apps—into precise, real-time articulations of five independent servo-driven fingers.

Our Solution / Methodology

We utilized the Uhand bionic robotic palm platform and focused heavily on systems integration and control logic. The methodology involved:

  • Hardware Assembly & Wiring: Integrated five anti-blocking LFD-01 servos and a 180-degree LD-1501MG digital pan-tilt servo with an Arduino-based expansion board.
  • Signal Mapping (RC Controller): Mapped a 6-channel FS-iA6B receiver to the Arduino. We programmed pulse-width modulation (PWM) logic to map incoming RC values (ranging from 1000 to 2000) directly to precise physical angles (30 to 120 degrees) for individual finger control.
  • Action Group Programming: Coded predefined sequences ("action groups") allowing complex grasping motions and gestures to be executed with a single button press on the controller.
  • Wireless Bluetooth Integration: Synced the control board with a mobile application via a 2.4 GHz Bluetooth module, establishing a dual-mode system where the hand could be controlled via an RC transmitter or a graphical mobile interface.

Key Integrations & Visuals

1. 6-Channel Digital Servo Telemetry

We utilized an FS-iA6B receiver to translate stick movements into independent finger controls. For example, right and left movements on specific channels were mapped directly to the individual servo motors controlling the digits.

2. Code Logic & Signal Processing

Developed software algorithms using the `` library to ingest signal pulses and write the exact required angles to the servos, ensuring power efficiency and zero-blocking jitter during operation.

3. Mobile Application Control Interface

Configured Bluetooth data transfer to allow manual slider manipulation for each finger, alongside custom programmed action-group triggering.

Conclusion & Impact

This project successfully navigated the complexities of multi-servo system integration, power optimization, and real-time software debugging. By successfully translating analog/digital commands into complex mechanical movements, this prototype demonstrates the foundational control theory required for advanced biomedical robotics, laying the groundwork for future integrations with Brain-Computer Interfaces (BCI) and surface electromyography (sEMG) technology.
